# Project Setup

1. #### clone repo
- http
    ```bash
    git clone https://github.com/Geekzix/calorie-snap-auth-service.git
    ```
- ssh
    ```bash
    git clone git@github.com:Geekzix/calorie-snap-auth-service.git
    ```

2. #### change dir
    ```bash
    cd calorie-snap-auth-service
    ```
3. #### pre-download package (optional)
    ```bash
    go mod download
    ```
4. #### build, run  or test app
    ```bash
    go build, go run, or go test
    ```
5. #### install atlas cli - [Docs](https://atlasgo.io/docs)
- Mac, Linux
    ```bash
    curl -sSf https://atlasgo.sh | sh
    ```
- Homebrew
    ```bash
    brew install ariga/tap/atlas
    ```
